# Pizza Sales Analysis & Interactive Dashboard

##  Project Overview

This project is an interactive **Pizza Sales Dashboard** created using Microsoft Excel to analyze pizza sales data and generate meaningful business insights.

The dashboard provides a clear overview of sales performance by analyzing **revenue, orders, pizzas sold, pizza categories, pizza sizes, days, hours, and individual pizza products**.

The objective of this project is to transform raw pizza sales data into an interactive and easy-to-understand dashboard that can help identify sales trends, customer ordering patterns, and top- and low-performing products.

---

## 🎯 Project Objectives

- Analyze overall pizza sales performance.
- Identify the busiest days and ordering hours.
- Analyze sales performance across pizza categories.
- Compare sales based on pizza sizes.
- Identify the best-selling pizzas.
- Identify the lowest-selling pizzas.
- Understand daily and hourly order trends.
- Create an interactive dashboard for business analysis.

## Key KPIs

The dashboard includes important business KPIs such as:

- **Total Revenue**
- **Average Order Value**
- **Total Pizzas Sold**
- **Total Orders**
- **Average Pizzas per Order**

These KPIs provide a quick overview of the overall sales performance.

---

## 📈 Dashboard Features

### 1. Daily Order Trend

Shows the number of orders received on each day of the week and helps identify the busiest days.

### 2. Hourly Order Trend

Analyzes order volume throughout the day to identify peak ordering hours.

### 3. Sales by Pizza Category

Shows the contribution of different pizza categories such as:

- Classic
- Supreme
- Veggie
- Chicken

### 4. Sales by Pizza Size

Analyzes sales distribution across different pizza sizes, including:

- Large
- Medium
- Small
- X-Large
- XX-Large

### 5. Total Pizzas Sold by Category

Compares the total number of pizzas sold across different categories.

### 6. Top 5 Best-Selling Pizzas

Identifies the five pizzas with the highest number of pizzas sold.

### 7. Bottom 5 Lowest-Selling Pizzas

Identifies pizzas with comparatively lower sales volumes.

### 8. Interactive Date Filter

The dashboard includes a date timeline that allows users to filter and analyze the sales data for different periods.

---

## 🔍 Key Insights

Some of the insights identified from the dashboard include:

- Friday and Saturday have high order volumes compared with several other days.
- Order activity is concentrated around lunch and evening hours.
- The Classic pizza category contributes significantly to overall sales.
- Large-size pizzas account for a major portion of pizzas sold.
- The Pepperoni Pizza is among the highest-selling pizzas.
- Some specialty pizzas have comparatively lower sales volumes.
